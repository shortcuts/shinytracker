shinytracker

Scan your Pokemon GO shiny box and track which shinies you've caught. The app reads your box via a screenshot-based Accessibility Service, matches each icon against a bundled sprite catalog, and keeps a local checklist of what you have.

This wiki is a placeholder while the app is still in early development. It will grow once the first release lands.

Install

  1. Download the latest APK from GitHub Releases (once available).
  2. Open the downloaded file. If you see a prompt to "Allow installs from unknown sources", turn it on in Settings for your browser or file manager, then come back and try again.
  3. You may see an "App scan recommended" message from Google Play Protect. This warning shows up for any app installed outside the Play Store, and it's nothing to worry about.
